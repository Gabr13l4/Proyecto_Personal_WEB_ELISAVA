# Context del projecte

## Informació general
- **Repositori:** `Paladini-Elisava/Projecte-Inicial`
- **Branca consultada:** `main`
- **Tecnologies:** HTML, CSS i JavaScript natius.
- **Project:** Dual Autoimmunity Digital Platform (Celiac Disease & Hashimoto’s Thyroiditis)
- **Current Phase:** Research Synthesis, UX Conceptualization & Visual Identity (Figma)
- **Design Tools:** Figma (UI layout, color system, interactive toggle wireframes)

## Fitxers principals
### `index.html`
Will define the split-screen landing page structure with the central interactive toggle slider (`Celiac | Intersection | Hashimoto's`) and rounded card components. `style.css` i `script.js`.

### `style.css`
Will apply clean sans-serif typography and the custom color palette (`#31263E`, `#FBF5F3`, `#FF8552`, `#8765DD`).

### `script.js`
Will handle the interactive tri-mode toggle switching between Celiac view, Hashimoto’s view, and the Intersection Hub, as well as interactive tracker utilities.

### `README.md`
Actualment conté només el títol del projecte.
