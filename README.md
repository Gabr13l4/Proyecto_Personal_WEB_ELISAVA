# In Common — Autoimmune care, connected

A responsive, three-section website prototype exploring the connection between celiac disease and Hashimoto’s thyroiditis. Built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub. Choose **Public** if you want the site to be publicly visible.
2. Upload the contents of this folder to the top level of the repository. Keep `index.html`, `style.css`, and `script.js` together at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the Pages deployment to finish. GitHub will show the published website address in **Settings → Pages**.

The site is static and needs no build step. The tracker, routine, and food prompts are front-end prototypes; they do not persist data or send reminders.
